# OreToggle (Optimized)

Optimized Minecraft plugin for toggling ore generation (removing ores in chunks within a configurable radius around the player)

Features:
- Player-based chunk processing
- Incremental chunk scanning
- TPS-safe architecture
- Persistent storage of removed ores for restoration

Commands:
- /oretoggle <ore> <on|off> (example: /oretoggle coal off)
- /restoreore <ore>
